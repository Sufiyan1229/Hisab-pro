ROKDO — Firebase integration preparation

What this package now contains:
- firebase.js: Firebase app, Authentication and Firestore initialization from Vite environment variables.
- .env.example: safe template for the Firebase Web App config values.
- firestore.rules: deny-by-default rules. A signed-in user can access only /businesses/{their-UID}/...

IMPORTANT CURRENT STATUS
- This is setup groundwork, NOT a completed Firebase login or cloud-data integration.
- Existing screens still use localStorage. Do not enter live customer/business data expecting cloud backup or multi-device sync.
- Do not publish firestore.rules until the app's data paths are migrated and tested. These rules intentionally deny the app's current localStorage-only workflow no Firestore access is currently used.
- Firebase Phone provider must be enabled. For real SMS OTP, Firebase billing/SMS quotas and authorized domains must be configured. Test phone numbers are not real SMS delivery.

SETUP
1. Copy .env.example to .env.local.
2. Fill values from Firebase Console > Project settings > Your apps > SDK setup > Config.
3. Never use a Firebase service-account JSON/private key in a browser app.
4. Keep .env.local out of Git. Vite VITE_ values are included in the browser bundle; they are app config, not secrets.
5. Before production, migrate all data to /businesses/{Firebase Auth UID}/... and test Firestore rules with the Firebase Rules emulator.
